# 🔬 AI Research Paper Explorer

A minimal, student-friendly web application that makes discovering and understanding academic research papers faster and less intimidating. 

🔗 **Live Demo:** https://github.com/samhitha-13/ai-research-explorer

## ✨ Features
* **Live Academic Search:** Fetches real-time open-access research papers, publication years, authors, and citation counts using the **OpenAlex API**.
* **One-Click PDF Access:** Jump straight to open-access full-text papers when available.
* **AI Breakdown (ELI5 Mode):** Uses the **Gemini API** to translate dense academic abstracts into three clear sections: *Plain-English Summary*, *Key Innovation*, and *Limitations*.
* **Zero-Backend Architecture:** Runs completely in the browser with client-side API key storage (`localStorage`) for privacy and instant deployment.

## 🛠️ Built With
* **Frontend:** HTML5, CSS3 (Glassmorphism UI), Vanilla JavaScript
* **Data API:** [OpenAlex API](https://docs.openalex.org/)
* **AI Synthesis:** [Google Gemini API](https://ai.google.dev/)
* **Hosting:** GitHub Pages
